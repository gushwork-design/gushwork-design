Gushwork design system

A Claude Code plugin. Install it once, and Claude builds Gushwork screens using the real components and tokens instead of guessing at them.

v1.37.0 · last updated 11 Aug 2026, 18:39 · changelog

Install

1
Add the plugin
Run this in a terminal.
claude plugin marketplace add utsav-gushwork/gushwork-design && claude plugin install gushwork-design@gushwork
OR
Don't want to use a terminal? Paste this into Claude Code instead and approve what it runs.
Set up the Gushwork Design System plugin for me:

1. Run: claude plugin marketplace add utsav-gushwork/gushwork-design
2. Run: claude plugin install gushwork-design@gushwork
2
Turn on auto-update
This is what keeps you current. Without it you stay on today's version forever, and stale versions fail silently — they emit last month's colours and spacing with full confidence. Paste this into Claude Code.
In ~/.claude/plugins/known_marketplaces.json, set "autoUpdate": true on the "gushwork" entry. Leave everything else in that file alone.
3
Restart Claude Code
The plugin does not take effect in the session you installed it from. Quit and start it again — this is the step people miss.

Verify

1
Check it's installed
You should see gushwork-design in the list.
claude plugin list
2
Check it fires
Ask Claude to build something with the Gushwork design system — a dashboard, a landing page, whatever you're working on. You don't have to name the skill; it triggers on the work.
The reply must open with one of these, depending on what you asked for:
Using the Gushwork dashboard skill — v1.37.0, updated 11 Aug 2026.
Using the Gushwork web skill — v1.37.0, updated 11 Aug 2026.
If that line is missing it didn't fire — restart again, or ask for the skill by name. The version in it is also how you catch a stale install: if it reads anything below v1.37.0, you're behind and it's emitting old values. It will ask two or three questions before building. That's deliberate.
