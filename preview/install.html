Gushwork design system

A Claude Code plugin. Install it once, and Claude builds Gushwork screens using the real components and tokens instead of guessing at them.

What this is

Two skills over one shared foundation — one for marketing web, one for the product dashboard — measured from the Gush Design System v2.0 Figma file. You never name them. Ask for a dashboard or a landing page and the right one fires, using real colours, spacing and type rather than approximations of them.

Currently v1.37.0. Works on any Claude account, personal or work — you don't need to be in the Gushwork org.

Install

This needs Claude Code, the terminal tool — not the claude.ai website. Check with claude --version; if that fails, install it from the setup guide first. 
claude plugin marketplace add utsav-gushwork/gushwork-design && claude plugin install gushwork-design@gushwork

Then restart Claude Code. The plugin does not take effect in the session you installed it from — this is the step people miss.

Prefer not to touch a terminal? Paste this into Claude Code instead and approve what it runs. It does the same thing, plus the auto-update flag.

Set up the Gushwork Design System plugin for me:

1. Run: claude plugin marketplace add utsav-gushwork/gushwork-design
2. Run: claude plugin install gushwork-design@gushwork
3. In ~/.claude/plugins/known_marketplaces.json, set "autoUpdate": true on the
   "gushwork" entry. Leave everything else in that file alone.

Then tell me to restart Claude Code.

Verify it worked

After restarting, check it's installed:

claude plugin list

You should see gushwork-design. Then check it actually fires — ask for something real:

Build a dashboard for the sales team to see show-ups over the week

The reply must open with “Using the Gushwork dashboard skill.” If that line is missing it didn't fire — restart again, or ask for the skill by name. It will ask two or three questions before building. That's deliberate.
