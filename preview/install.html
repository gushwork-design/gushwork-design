Install the Gushwork design system

Five minutes. Works on any Claude account — personal or work. You don't need to be in the Gushwork org, and nobody has to grant you access.

This is a plugin for Claude Code, the terminal tool — not the claude.ai website. Pasting these commands into the claude.ai chat box does nothing.

Before you start

0
Check you have Claude Code
Run this in a terminal. If you get a version number, you're set. If you get “command not found”, install it first from the setup guide.
claude --version

The easy way

Paste this into Claude Code and approve the commands it runs. It does all four steps, including the auto-update flag most people skip.

Set up the Gushwork Design System plugin for me:

1. Run: claude plugin marketplace add utsav-gushwork/gushwork-design
2. Run: claude plugin install gushwork-design@gushwork
3. In ~/.claude/plugins/known_marketplaces.json, set "autoUpdate": true on the
   "gushwork" entry. Leave everything else in that file alone.
4. Verify with: claude plugin list

Then tell me to restart Claude Code, and give me three lines on how to use it.

Or run it yourself

1
Add the marketplace, then install
This repo is its own single-plugin marketplace, which is why it's two commands — claude plugin install resolves a plugin name from a marketplace, not a git URL. Installs at user scope, so it's live in every project you open.
claude plugin marketplace add utsav-gushwork/gushwork-design && claude plugin install gushwork-design@gushwork
2
Restart Claude Code
This is the step people miss. The plugin does not take effect in the session you installed it from. Quit Claude Code and start it again.
3
Confirm it's there
You should see gushwork-design in the list.
claude plugin list

Check that it actually fires

Ask for something real. You never name the skills — they trigger on the work.

Build a dashboard for the sales team to see show-ups over the week

The reply must open with “Using the Gushwork dashboard skill.” If that line is missing, it didn't fire — restart again, or ask for the skill by name. It will ask two or three questions before building. That's deliberate, not a stall.

Don't skip the auto-update flag

Step 3 of the paste block sets "autoUpdate": true. It isn't required to make the plugin work, which is exactly why it gets skipped — and then stale versions fail silently. They emit last month's colours and spacing with full confidence. No error, no warning, just quietly wrong output.

If you skipped it, update by hand whenever things look off. Restart after — a new version takes effect on the next start, not the current one.

claude plugin marketplace update gushwork && claude plugin update gushwork-design@gushwork
