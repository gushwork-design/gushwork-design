GTM Command Center — component audit

Every element in the three exported dashboards (overview, meta-ads, admin/targets, captured 10 Aug 2026), measured off the markup and CSS, then mapped against what exports/dashboard/ already documents. 62 components. The point of the sheet is the last column: what the library covers, what it needs a variant for, and what isn't there at all.

Headline: the dashboard shares almost nothing with the design system but the blue. It runs its own token set (--brand-500, --surface, --text-muted…) with no relationship to --gw-*; it sets type in Plus Jakarta Sans, which is not a Gushwork face and means the display face never appears; and its central component — a progress-to-target KPI card — has no counterpart, because the library's kpi-card is a period-over-period delta card. 8 of 23 colour tokens match a Gushwork token exactly. 8 of 62 components can be instanced as they stand.
The 21 missing elements are drawn. preview/dashboard-new-elements.html — 21 elements, every value an existing --gw-* token, black as the control colour, no palette additions. The 32 Extend items are variants on components that already exist and belong in those components' specs.

3No persistent inline alert The Overview alert stack, and any future channel warning toast is closer than it looks — it already ships Light/Dark × Error/Warning/Success/Info. What's missing is a placement: persistent, inline, full-width, stacked, with a channel label. Add that rather than a new component, and the four state colours come for free. The stack container is genuinely new.
4Table has no grouped header, sticky column or inline-bar cell Daily Breakdown on both pages, Channel Breakdown, Targets Three additions to table: a 2-row header with colgroup spans, a pinned first column, and a cell that pairs value/target with a 40px bar. Settle the conflict first — table-row rules against darkening the first column and all three of these tables do it.
5No segmented control The date-range control on both dashboards controls/toggle is a switch and controls/tab is navigation, so this is a third thing: a radio group with a sliding indicator whose last segment opens dropdown-options Style=Calendar. That calendar is itself still RULED, pending Figma, and needs range selection the ruling never covers.
6Underline tab is not a tab variant The 9-item page nav A Style property on controls/tab — pill (built) against underline (not) — plus overflow behaviour, since the library's ships exactly 5 items and this needs 9 that scroll.
7No green or red that exists in Gushwork Every status colour on every surface --on-track #0d9463 and --critical #dc2626 are in neither ramp, in neither theme. Either pick from green-* and red-* and accept the shift, or add steps. The yellows already match exactly, so only two decisions are actually open.
8Plus Jakarta SansAll type on all three pages Swap to Inter for body and Vert Grotesk Display for headings and card values, which is what the library's own cards do. It also removes the 11/13/15px steps for free, since the ramp has none of them.

Method. Style and script blocks were stripped from each export and the remaining DOM parsed to a tree; repeated siblings were collapsed so each distinct structure counts once, and every distinct tag + class pair was tallied — 205 across the three pages — so nothing here was inventoried by eye. Dashboard values come from the exports' own globals.css; Gushwork values from foundation/tokens.css; library claims from exports/dashboard/*.md and foundation/shared-components.md.

  • Specimens are re-implementations from the measured CSS, not copies of the export markup. They carry no Tailwind, and .dash is the only place in this sheet where a raw hex appears — every library-side specimen is built from --gw-* alone.
  • Plus Jakarta Sans is not committed to this repo, so specimen text renders in Inter. Sizes, weights, colours, radii and spacing are exact; letterforms are not.
  • The library progress-bar specimen has its 32px track drawn at 20px to fit the cell. Every other value in it is the real one.
  • Controls are inert — the segmented indicator, hovers, tooltips and dismiss buttons are drawn in their resting state, not wired.
